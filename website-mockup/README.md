# Holt website mockup

This folder is a design artifact, not a production website. The page is a
single self-contained HTML file with no build system, analytics, external
assets, or deployment configuration.

Open `index.html` directly in a browser to review the direction. The canonical
repository links target `github.com/holt-oss/holt`, and the distribution name
shown in the install command is `holt-cli` while the executable remains `holt`.
The license link targets the chosen Apache-2.0 license in that repository.

## Direction in this version

- A dark, authored developer-tool identity drawn from Holt's real terminal UI.
- One direct premise, followed immediately by the install command and product.
- A numbered evidence trail replaces generic feature cards and marketing tiles.
- The actual TUI screenshot is the hero artifact; it is not placed in fake
  browser chrome or floated over decorative graphics.
- The award stays supporting proof, while the measured workflow is the argument.
- All headline performance claims come from the repository's current README.
