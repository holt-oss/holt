03why it exists

GitHub counts both of these as one closed pull request.

Stars, issue counts, and repository activity describe project health. They do not tell you what happens when a stranger tries to contribute. The useful signal lives inside the conversations.

04the trace

The model can write the report. It cannot choose the verdict.

Holt turns repository history into typed findings, verifies every evidence ID, then hands the surviving facts to a plain deterministic function. Verification only removes unsupported claims; narration cannot change the answer.
